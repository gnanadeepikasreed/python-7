
# Retail Billing with Multiple Discount Rules

## Description
This project calculates retail bills for multiple products by applying different discount rules.

## Features
- Accepts product details.
- Calculates product amounts.
- Applies applicable discounts.
- Calculates the final bill.
- Displays billing information.

## Concepts Used
Variables, operators, conditional statements, loops, and lists.

## Language
Python 3

## How to Run
python Retail_Billing.py
